# Замер КС — приложение для планшета

Офлайн-приложение замера квартиры (Android/HarmonyOS, Huawei MatePad SE 11).
Веб-часть: `app/src/main/assets/index.html`. Сборка APK — GitHub Actions (`.github/workflows/zamer-apk.yml`) при пуше в ветку `zamer-ks-apk`.
Готовый файл: релиз `zamer-ks` → `ZamerKS.apk`.
