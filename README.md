# Shumm

Личное рабочее пространство руководителя отдела продаж: работа, финансы, развитие,
ежедневные дела и сводная главная панель.

## Что в репозитории

| Путь | Что это |
|---|---|
| `PROMPT.md` | Требования к продукту: разделы, агенты, расписание, критерии готовности |
| `design/proposal.html` | Утверждённое дизайн-направление «Пульт 68» с разбором стиля |
| `app/app.html` | Само приложение: разметка, стили и логика одним фрагментом |
| `app/manifest.webmanifest`, `app/sw.js`, `app/icon*.svg` | Обвязка устанавливаемого приложения |
| `build.py` | Собирает фрагмент в самостоятельную страницу `dist/index.html` |

## Сборка

```
python3 build.py
```

Скрипт кладёт в `dist/` полную страницу вместе с манифестом, service worker и иконками.
Содержимое `dist/` можно выложить на любой статический хостинг с HTTPS: без него
браузер не даст установить приложение и не включит офлайн-режим.

## Хранение данных

Внутри Claude приложение пишет данные в хранилище артефакта, поэтому операции,
задачи и цели видны и на телефоне, и на ноутбуке. При запуске с собственного
хостинга того же хранилища нет, и приложение переходит на память браузера:
данные остаются на одном устройстве. Общая база для собственного хостинга
подключается отдельно, вместе с интеграциями.

## Чего ещё нет

Рабочие цифры на экране «Работа» демонстрационные и помечены как демо.
Они станут настоящими после подключения AmoCRM, таблицы отчёта, Telegram,
календаря и источников погоды и новостей. Список нужных доступов — в `PROMPT.md`.
